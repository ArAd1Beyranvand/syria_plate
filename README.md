# syria_plate

Syria's current licence plates for `plate_core`: the transitional government's plate (private black, commercial maroon) and the AANES plates (trilingual and bilingual cars in private, commercial, security and administrative colours, and motorcycles), with their themes, alphabets in `plate_alphabet`, and an advisory validator.

```dart
PlateCanvas(
  spec: SyriaPlates.transitional,
  theme: SyriaThemes.commercial,
  validator: const SyriaTransitionalValidator(),
  autoValidate: true,
)
```

## Also available

- [`plate_core`](https://pub.dev/packages/plate-core) - Paint license plates.
- [`plate_alphabet`](https://pub.dev/packages/plate-alphabet) - A library of alphabets for license plates.
